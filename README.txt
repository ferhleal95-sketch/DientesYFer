# Fer & Dientes — página romántica

Esta carpeta contiene una página web lista para publicar con GitHub Pages.

## Publicarla gratis con GitHub Pages

1. Entra a https://github.com/ y crea una cuenta si no tienes una.
2. Crea un repositorio nuevo, por ejemplo: `fer-dientes`.
3. Sube **todos** los archivos de esta carpeta (`index.html` y las 6 fotos).
4. En el repositorio ve a **Settings → Pages**.
5. En "Build and deployment", selecciona **Deploy from a branch**.
6. Selecciona la rama `main` y la carpeta `/ (root)`.
7. Guarda. GitHub te dará una dirección parecida a:
   `https://TUUSUARIO.github.io/fer-dientes/`

La canción usa el reproductor oficial de Spotify y también tiene un botón para abrirla directamente en Spotify.
